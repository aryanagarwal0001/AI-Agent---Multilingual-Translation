# Multilingual Translation AI Agent

## Overview
This project demonstrates an AI agent capable of translating a single English input into multiple languages simultaneously. Built using Gemini‑3.1‑Flash‑Lite LLM, the agent produces parallel outputs in French and Spanish, showcasing real‑time multilingual orchestration.

## Tech Stack
- LLM: Gemini‑3.1‑Flash‑Lite  
- Frameworks: LangChain (for agent orchestration)  
- Prompt Engineering: Optimized templates for parallel translation  
- Evaluation: Manual validation of translation accuracy  

## Features
- Accepts English input and returns instant translations in French & Spanish.  
- Demonstrates parallel multilingual output generation.  
- Highlights versatility of AI agents beyond retrieval and computation.  
- Scalable design for adding more languages in future.
